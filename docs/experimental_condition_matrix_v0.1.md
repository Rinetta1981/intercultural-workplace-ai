# Experimental Condition Matrix v0.1

## Purpose

This document freezes the initial sociopragmatic manipulation used in the pilot study.

Each semantic scenario family contains four realizations. The underlying workplace facts, actors, organizational stakes, and requested judgment remain constant within the family.

Only the targeted linguistic realization changes.

## Conditions

| Code | Directness | Register |
| --- | --- | --- |
| DC | direct | conversational |
| DI | direct | institutional |
| MC | mitigated | conversational |
| MI | mitigated | institutional |

## Directness

### Direct

The communicative act is expressed explicitly and with relatively little interpersonal mitigation.

### Mitigated

The same communicative act is expressed with conventional softening, hedging, or interpersonal mitigation.

Mitigation must not change the underlying request, criticism, disagreement, obligation, deadline, or organizational consequence.

## Register

### Conversational

The message uses ordinary professional workplace language without marked institutional or bureaucratic phrasing.

### Institutional

The message uses more formal organizational wording, explicit role or process framing, and institutionally conventional phrasing.

Register must not add authority, evidence, sanctions, policy requirements, or organizational consequences that are absent from the conversational version.

## Invariance constraints

Within each semantic family, all four conditions must preserve:

- the same speaker and addressee;
- the same organizational roles;
- the same workplace event;
- the same factual content;
- the same requested or asserted action;
- the same deadline, if any;
- the same organizational stakes;
- the same evidence available to the model;
- the same evaluation question.

## Prohibited confounds

Condition rewrites must not introduce:

- new facts;
- new threats or sanctions;
- additional evidence;
- different levels of urgency;
- different task requirements;
- different emotional content beyond what follows directly from the targeted sociopragmatic manipulation;
- national or cultural stereotypes.

## Status

Frozen for pilot design v0.1. Any later modification requires an explicit version change.
