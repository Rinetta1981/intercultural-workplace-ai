# Zero-Cost Preflight Checklist v0.2

Do not begin substantive collection until every applicable item is checked.

## Gemini

- [ ] AI Studio shows the research project on the **Free** tier.
- [ ] Billing has not been enabled/upgraded for this study.
- [ ] Model is `gemini-3.8-flash`.
- [ ] Thinking level is `low`.
- [ ] Search grounding is disabled.
- [ ] Other tools are disabled.
- [ ] Structured-output schema works in a dry run.
- [ ] A 429/quota error causes pause, not upgrade.

## ChatGPT Business

- [ ] Correct Business workspace is selected.
- [ ] GPT-5.6 Sol is available.
- [ ] Medium reasoning is available.
- [ ] Each observation uses Temporary Chat.
- [ ] Each Temporary Chat is **Unpersonalized**.
- [ ] No web search, files, apps, plugins, connectors, GPTs, or Projects are used.
- [ ] No purchased workspace credits will be used for the study.
- [ ] Auto-reload/additional paid usage will not be enabled for the study.
- [ ] If included usage is exhausted, collection stops until reset.
- [ ] A visible fallback to another model invalidates that attempt.

## Research freeze

- [ ] Frozen stimulus fingerprint recorded.
- [ ] Queue fingerprint recorded.
- [ ] v0.2 system-set fingerprint recorded.
- [ ] Statistical analysis plan committed before substantive outputs are inspected.
